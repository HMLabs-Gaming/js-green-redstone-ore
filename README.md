# JS Green Redstone Ore

[![Modrinth](https://cdn.jsdelivr.net/npm/@intergrav/devins-badges@3/assets/cozy/available/modrinth_vector.svg)](https://modrinth.com/project/OGW3adGA)

A simple texture pack that turns the normal and deepslate redstone ore Block completely green. No other changes made. Perfect for much better visibility and compatible with all Minecraft versions.
